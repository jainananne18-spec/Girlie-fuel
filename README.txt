Girlie Fuel app package (v5)

FILES
  index.html     the app
  manifest.json  lets it install on your iPhone Home Screen
  sw.js          lets it work offline
  icon-192.png / icon-512.png

WHAT'S NEW IN v5
  - Me tab: profile photo, name, birthday/age, address, height, weight,
    BMI, healthy weight range and desired weight
  - Sleep tab: tap Sleep / I'm awake, hours are calculated and logged,
    "are you awake?" prompt when you reopen the app during the night,
    sleep log you can edit
  - Weight tab: progress chart, goal progress bar, waist & hips log
  - More tab: weekly report, backup & restore
  - New pastel pink look and a bottom menu with 6 tabs
  - Food log for each day, per-day meal edits, smoothie how-tos (from v4)

PRIVACY
  Your personal info is typed into the app and stays on your phone.
  It is NOT stored in these files, so it is safe on a public GitHub repo.

PUT IT ON GITHUB
  Replace the files in your repository with these, commit, and let GitHub Pages redeploy.
  On iPhone: open the site in Safari > Share > Add to Home Screen.
  If you still see the old version, close the app and reopen it once.

Calories and BMI are estimates, not medical advice.
