Girlie Fuel app package (v3)

FILES
  index.html     the app
  manifest.json  lets it install on your iPhone Home Screen
  sw.js          lets it work offline
  icon-192.png / icon-512.png

WHAT'S NEW IN v3
  - Smoothies tab: 7 recipes (low-fat milk, oats, chia; no added sugar/honey/syrup)
  - Save favorites with the heart button
  - "Add to today" counts the smoothie in your daily calories
  - Smoothie shopping list built from the recipes you pick
  - Water tracker (250 mL glasses) on the Today screen
  - Added the missing manifest.json and sw.js

PUT IT ON GITHUB
  Replace the files in your repository with these, commit, and let GitHub Pages redeploy.
  On iPhone: open the site in Safari > Share > Add to Home Screen.
  If you still see the old version, close the app and reopen it once.

Calories are estimates, not medical advice.
